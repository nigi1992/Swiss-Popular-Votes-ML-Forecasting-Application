# Swiss-Popular-Votes-ML-Forecasting-Application
GitHub Repository for my MA-Thesis on building a ML Forecasting Tool for predicting the Outcome of Swiss Popular Vote Elections

**Title:** _"Pre-Campaign Signals and Referendum Outcomes: Can Swiss federal votes be predicted before the first poll is published?"_

## Author 👋

Nicolas

## Input Data 🗃
The folder "Input Data" is where the Datasets can be found. 
I used the dataset from Swiss Votes (2026) https://swissvotes.ch/page/dataset

Additional datasets: 
Parlament.ch (2026): https://www.parlament.ch/de/ratsbetrieb/abstimmungen

Let me know, if you want the raw data.  

## Scripts 💻
You'll find the R scripts in the folder "Scripts".

Change YOUR_BASE_PATH to your own base_path location to run the scripts.

Scripts should be run in the intended numerical order. However, all input data and all output files are already present in the respective folders and is ready for inspection.

Input Data for Fraktionen_Blocs was collected and prepared in another of my GitHub Repositories: https://github.com/nigi1992/NR-Roll-Call-Final-Vote-Data-Faction-Scraper
But it is also not necessary to run it. The respective scripts are already present in this repository.

## Output 🚀
You'll find all Output files and figures in the folder "Output".
