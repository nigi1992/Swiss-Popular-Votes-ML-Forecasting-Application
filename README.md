# Swiss-Popular-Votes-ML-Forecasting-Application
GitHub Repository for my MA-Thesis on building a ML Forecasting Tool for predicting the Outcome of Swiss Popular Vote Elections

**Current Working Title:** _“Running the entire history of Swiss direct democracy through a machine learning black box – Can the results of Swiss national referendums be predicted before political opinion polls are published?”_

**Research question:** _“What factors drive the acceptance and rejection of referendums at the national levels in Swiss direct democracy?”_
